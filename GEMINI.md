# AskChips Web Project Instructions

## Project Context
- **Name**: AskChips Website Redesign
- **Core Value**: Modern, reliable, and high-converting B2B portal for electronic components sourcing and PCB/PCBA manufacturing.
- **Visual Aesthetic**: Clean Industrial / Hi-Tech — crisp typography (Inter + JetBrains Mono), clean white/slate canvas with high-contrast borders and tech accents (cobalt blue `#2563eb`, emerald green `#059669`).
- **Stack**: Vite multi-page + Tailwind CSS + Vanilla ES2022 JavaScript + Lucide Icons.
- **Reference Assets**: Located in `.init_docs/origin_old_site` (photos, certifications, equipment specs).

## Planning & Workflow
This project uses the GSD (Get Stuff Done) planning system located in `.planning/`:
- `.planning/PROJECT.md`: Project vision, core value, active requirements, decisions.
- `.planning/REQUIREMENTS.md`: Detailed checkable v1/v2 requirements and traceability.
- `.planning/ROADMAP.md`: Phase breakdown, success criteria, and progress tracking.
- `.planning/STATE.md`: Living project state and velocity tracker.

## Development Guidelines
- Always prioritize semantic HTML5 and accessible UI elements.
- Maintain high-performance standards: responsive images, zero-dependency runtime scripts, no heavy unused libraries.
- For phase execution, follow the standard GSD sequence: `/gsd-discuss-phase <N>`, `/gsd-plan-phase <N>`, `/gsd-execute-phase <N>`, `/gsd-verify-work <N>`.
