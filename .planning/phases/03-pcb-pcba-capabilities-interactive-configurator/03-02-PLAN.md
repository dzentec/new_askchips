<task type="auto" id="03-02-01">
<title>Develop Reactive PCB Configurator Component</title>
<instruction>
Create `src/js/components/pcb-configurator.js` with:
1. Reactive state object:
   ```javascript
   const pcbState = {
     layers: '2 Layers',
     material: 'FR4 Standard TG140',
     lengthMm: 100,
     widthMm: 100,
     thickness: '1.6mm',
     copperWeight: '1oz / 1oz',
     finish: 'Lead-Free HASL (RoHS)',
     solderMask: 'Green',
     silkscreen: 'White',
     quantity: '5 pcs'
   };
   ```
2. Dynamic rendering function that generates the 2-column workbench:
   - Left Column: Form controls with interactive chips for all options:
     - Layers: `1 Layer`, `2 Layers`, `4 Layers`, `6 Layers`, `8 Layers`, `10 Layers`, `12 Layers`, `16+ Layers`
     - Base Material: `FR4 Standard TG140`, `High-TG170 FR4`, `Rogers (RF High-Freq)`, `Aluminum Core`, `Polyimide Flex`
     - Dimensions: inputs for Length (mm) and Width (mm) with fast presets `50x50mm`, `100x100mm`, `150x100mm`
     - Board Thickness: `0.6mm`, `0.8mm`, `1.0mm`, `1.2mm`, `1.6mm`, `2.0mm`, `2.4mm`
     - Copper Weight: `1oz / 1oz`, `2oz / 1oz`, `2oz / 2oz`, `3oz / 2oz (Heavy)`
     - Surface Finish: `Lead-Free HASL (RoHS)`, `ENIG (Immersion Gold)`, `HASL with Lead`, `Immersion Silver`, `OSP`
     - Solder Mask: color swatches for `Green`, `Matte Black`, `Blue`, `Red`, `White`, `Yellow`
     - Silkscreen: `White`, `Black`
     - Quantity: `5 pcs`, `10 pcs`, `20 pcs`, `50 pcs`, `100 pcs`, `500 pcs`, `1000+ pcs`
   - Right Column: Sticky real-time specification summary card (`#spec-summary`):
     - Calculates total batch area in $m^2$ and $cm^2$
     - Calculates turnaround SLA (24h Express for 1-2L, 48-72h for 4-6L, 5-7 days for 8+L / Rogers / Flex)
     - Shows all active parameter selections in JetBrains Mono
     - "Submit Parameters for Instant RFQ" button with loading feedback
3. Event handling:
   - Clicking any chip updates `pcbState` and re-renders active styles and summary values.
   - Updating dimensions inputs recalculates area and dimensions immediately.
   - Submitting serializes `pcbState` into `localStorage.setItem('askchips_pcb_config', JSON.stringify(pcbState))` and navigates to `/contact.html?source=pcb_config`.
</instruction>
