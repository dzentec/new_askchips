<task type="auto" id="04-02-01">
<title>Develop Universal RFQ Modal Dialog Component</title>
<instruction>
Create `src/js/components/rfq-modal.js` featuring:
1. Modal DOM Mount:
   - Centered dialog container with `fixed inset-0 z-50 bg-slate-900/60 backdrop-blur-sm flex items-center justify-center p-4`
   - Smooth entrance animation and backdrop click / Escape key listener to close
   - Accessible ARIA attributes (`role="dialog"`, `aria-modal="true"`)
2. Form Fields & Interactions:
   - Project Type selection pills: `Electronic Components`, `PCB Fabrication`, `Turnkey PCBA`, `BOM Cost-Down`
   - Full Name, Work Email (validated via regex), Company Name, Phone / WhatsApp (optional)
   - Embedded BOM dropzone (using `initBomUploader`)
   - Pre-filled PCB configuration banner if `localStorage.getItem('askchips_pcb_config')` is detected
   - Message / Target lead-time textarea
3. Submission Feedback State:
   - Animated SVG spinner on submit button
   - Mock network delay (~500ms) leading to green checkmark confirmation screen
   - Unique generated RFQ Tracking Code: `ASK-2026-` + random 4-digit number (e.g. `ASK-2026-8941`)
   - Reassurance copy: "Our technical procurement team is analyzing your specifications. You will receive an itemized quote within 24 hours."
4. Export API & Global Listeners:
   - `export function initRfqModal()`: mounts dialog container and listens for clicks on `[data-trigger="rfq-modal"]`
   - `export function openRfqModal(options = {})`: programmatically opens dialog with optional pre-filled values
   - Expose `window.openRfqModal = openRfqModal`
</instruction>
