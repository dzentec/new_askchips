<task type="auto" id="04-01-01">
<title>Develop Interactive BOM Dropzone & Validation Engine</title>
<instruction>
Create `src/js/components/bom-uploader.js` featuring:
1. Drag-and-Drop Dropzone UI:
   - Dashed high-contrast border (`border-2 border-dashed border-slate-300 rounded-xl p-6 sm:p-8 text-center cursor-pointer transition-all`)
   - Hover and dragover states (`border-blue-500 bg-blue-50/50`)
   - Hidden native file input accepting `.xlsx,.xls,.csv,.txt,.zip`
   - Cloud upload SVG icon with hover scale micro-animation
   - Copy: "Click to select BOM file or drag & drop here" + "Supports Excel (.xlsx, .xls) and CSV up to 15MB • Confidentiality Guaranteed"
2. Validation Engine:
   - Max file size: 15MB (`15 * 1024 * 1024` bytes)
   - Allowed extensions: `xlsx`, `xls`, `csv`, `txt`, `zip`
   - Error handling: Displays prominent red alert banner for invalid extension or oversized files with clear remediation instructions.
</instruction>

<task type="auto" id="04-01-02">
<title>Implement Client-Side File Inspector & Attachment Card</title>
<instruction>
Add file inspection and preview capabilities in `src/js/components/bom-uploader.js`:
1. Metadata & Row Inspector:
   - Formats file size dynamically (e.g. `245 KB` or `2.4 MB`)
   - Uses `FileReader` to read text/CSV files and estimate line item count (excluding header/empty lines)
   - For binary spreadsheets (.xlsx/.xls), calculates estimated row count from file payload
2. Populated Attachment Card UI:
   - Green-tinted container (`border border-emerald-200 bg-emerald-50/50 rounded-xl p-4 flex items-center justify-between`)
   - File icon + File name with `font-semibold text-slate-900 truncate`
   - Metadata badge: `font-mono text-xs text-slate-600` (e.g. `48 KB • ~35 line items`)
   - "Remove File" button with red destructive styling (`text-red-600 hover:text-red-700 text-xs font-semibold`)
3. Export API:
   - `export function initBomUploader(containerId, options = {})`
   - Supports `onFileChange(fileData)` callback providing file name, size, estimated rows, and raw File object for parent forms.
</instruction>
